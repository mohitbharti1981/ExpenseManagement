# Expense Tracker — Free Tier Stack

## Setup
cd Project/ExpenseManagement
source venv/bin/activate
pip install -r requirements.txt
python3 database.py          # init / migrate DB (safe to re-run)
python3 app.py               # http://127.0.0.1:5000

## Optional OCR (future scaling)
brew install tesseract       # macOS
pip install pytesseract Pillow

## DB reset (only if schema is broken)
rm expenses.db && python3 database.py
